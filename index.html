문제 정의

분실물의 접수·인식·보관·반환 과정이 사람 손을 많이 타고 대기 시간이 길다는 점에 착안해, 사람 개입을 최소화한 멀티로봇 협업 관리 시스템을 구현했습니다. 2인 팀 프로젝트로, 컴퓨터 비전 · 매칭 알고리즘 · TurtleBot 자율주행을 담당했습니다.

핵심 기능

  • YOLOv8 기반 분실물 카테고리 분류 및 OpenCV 배경 분리·색상 추출
  • 픽셀 좌표 → Dobot 좌표 homography 변환으로 정밀 피킹 좌표 산출
  • LLM 기반 분실물 ↔ 신고 유사도 매칭 (시간 · 장소 · 설명)
  • 임계값 2단계 분기 — 자동 매칭 / 관리자 검토 / 계속 탐색
  • slam_toolbox 기반 사전 맵 생성 및 AMCL 위치 추정
  • Nav2 기반 창고 ↔ 반환 창구 자율주행

시스템 구성

비전 시스템 MY PART

  • 작업대 위 분실물 촬영 후 YOLOv8 탐지 → 색상 추출 → LLM 자연어 설명 생성
  • 카메라 캘리브레이션과 homography로 Dobot 픽업 좌표 변환

매칭 시스템 MY PART

  • 같은 카테고리 · 최근 30일 이내 후보로 필터링 후 유사도 점수 계산
  • 점수 기준으로 자동 매칭 / 검토 / 탐색 상태 분기 및 인증코드 · 메일 트리거

TurtleBot 자율주행 MY PART

  • named pose(Dobot 근처, 반환 창구, 대기) 기반 목표 이동
  • Nav2 navigate_to_pose 액션으로 경로 계획 및 장애물 회피

Dobot · 백엔드 · 키오스크 TEAM

  • ROS 2 / rosbridge / REST로 비전 · 매칭 · 주행 모듈과 연동

문제 해결

카메라가 인식한 픽셀 좌표와 Dobot의 실제 좌표가 맞지 않아 피킹이 빗나갔습니다.

체커보드 캘리브레이션으로 카메라 파라미터를 보정하고, homography 변환으로 픽셀 중심을 Dobot 좌표로 매핑해 피킹 정확도를 확보했습니다.

매칭 임계값을 하나만 두면 애매한 후보에서 오매칭 또는 누락이 발생했습니다.

자동 매칭 임계값과 검토 임계값을 분리해, 애매한 구간은 관리자 검토로 넘기는 2단계 구조로 오매칭을 줄였습니다.

최소한의 안전 수칙을 지키지 않아 더 큰 사고로 이어지는 상황을 줄이기 위해, 안전 조건을 만족해야만 작동하는 킥보드 시스템을 구현했습니다.

문제 해결

머리카락 때문에 터치 센서가 정확히 동작하지 않았습니다.

헬멧은 머리에 밀착 착용하는 것이 올바르다는 점을 반영해, 스위치 센서로 착용 여부를 지속 확인하도록 변경했습니다.

헬멧부와 킥보드부 간 데이터 전송 시 여러 값을 개별 전송하면 지연이 발생했습니다.

알코올 수치와 헬멧 착용 여부 데이터를 하나로 통합하고, 타이머 기반으로 전송해 지연을 줄였습니다.

문제 해결

Jetson Nano에서 이미지 분석부터 위치 조절까지의 처리 속도가 느려 버퍼링과 인식률 저하가 발생했습니다.

모든 센서 스트리밍 구조를 점검하고 카메라 프레임 수를 조정해 파이프라인을 최적화했습니다.

드론의 불안정한 비행으로 통신까지 불안정해지는 문제가 있었습니다.

하드웨어를 물리적으로 더 단단하게 결합해 진동을 줄이고 통신 안정성을 높였습니다.

제어 방식에 대해 속도 제어와 위치 제어 사이에서 팀 내 의견 차이가 있었습니다.

두 방식을 모두 구현해 실험하고 실제 안정성을 비교한 뒤, 속도 제어 방식을 채택했습니다.

사용자의 표정에서 감정을 예측하고, 사용자 이력까지 반영해 감정 기반 음악을 추천하는 웹사이트를 구현했습니다.

  • K-NN 기반 사용자 식별
  • Spotify API 기반 음악 추천 및 재생
  • Flask 기반 웹페이지 구현
  • SQLite3 기반 이용 기록 저장

문제 해결

초기 표정 인식 모델의 정확도가 낮았습니다.

기존 데이터셋이 서양인 및 흑백 위주라는 점을 먼저 분석했습니다.

동양인 비중이 높은 데이터셋을 추가하고, angry / neutral 클래스 수 불균형을 확인했습니다.

가중치 조정과 data augmentation(cut-out, crop, noise 등)을 적용해 모든 클래스에서 85% 이상의 정확도를 달성했습니다.

사용자 식별에 ResNet 계열 모델을 사용하면 재학습 시간이 길고 데이터도 충분하지 않았습니다.

K-NN을 활용해 적은 데이터로도 빠르게 사용자 데이터를 구축하는 방식으로 전환했습니다.
